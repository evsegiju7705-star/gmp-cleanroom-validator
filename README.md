# Протоколы аттестации чистых помещений

Локальное веб-приложение для комплекса чистых помещений: общие данные объекта, приборы,
перечень помещений, замеры и печатные протоколы. Заменяет рабочую книгу Excel.
Методика: ГОСТ Р ИСО 14644-1-2017, ГОСТ Р ИСО 14644-3-2020.

## Запуск

Откройте `index.html` в браузере. Установка и интернет не нужны.
Данные хранятся только в вашем браузере; кнопки «Сохранить в файл» и «Загрузить из файла»
переносят их между компьютерами.

## Что готово

Общие данные, приборы с контролем срока поверки, перечень помещений с проектными данными и одиннадцать испытаний,
каждое с вводом замеров, расчётом, выводом и печатным протоколом:

- концентрация аэрозольных частиц (помещение и рабочая зона);
- температура и относительная влажность;
- перепад давления;
- расход воздуха и кратность воздухообмена;
- однородность скорости потока;
- целостность фильтров;
- эффективность фильтров (интегральный проскок);
- освещённость;
- уровень звука;
- время восстановления.

## Чего нет

Схем расположения точек на плане, справочных приложений к протоколам, нумерации страниц,
сквозной нумерации протоколов между испытаниями.

## Устройство

- `js/ref.js` — справочные таблицы (пределы по классам, таблица А.1, время отбора).
- `js/calc.js` — расчёты.
- `js/store.js` — хранение, экспорт, импорт.
- `js/protocol-skch.js`, `js/protocol-tivl.js` — печатные формы протоколов частиц, температуры и влажности.
- `js/tests.js` — описания и расчёты остальных испытаний.
- `js/engine.js` — общий экран ввода и печатная форма для них.
- `js/app.js` — экраны ввода.

Перед применением в аккредитованной деятельности сверьте справочные значения и результаты
расчётов с действующими редакциями стандартов и проведите валидацию по своей процедуре.
