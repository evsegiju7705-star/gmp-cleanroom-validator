# Протоколы аттестации чистых помещений

Локальное веб-приложение для комплекса чистых помещений: общие данные объекта, приборы,
перечень помещений, замеры и печатные протоколы. Заменяет рабочую книгу Excel.
Методика: ГОСТ Р ИСО 14644-1-2017, ГОСТ Р ИСО 14644-3-2020.

## Запуск

Откройте `index.html` в браузере. Установка и интернет не нужны.
Данные хранятся только в вашем браузере; кнопки «Сохранить в файл» и «Загрузить из файла»
переносят их между компьютерами.

## Что готово

- Общие данные: лаборатория, объект, заказчик, исполнители, условия.
- Приборы с контролем срока поверки.
- Перечень помещений с расчётом минимального числа точек отбора (таблица А.1).
- Концентрация аэрозольных частиц: ввод проб, среднее по точке, вывод, печатный протокол.
- Температура и относительная влажность: замеры по точкам, сравнение с проектной нормой, печатный протокол.

## Что впереди

Перепад давления, скорость и расход воздуха, однородность потока,
целостность и эффективность фильтров, освещённость, уровень звука, время восстановления.

## Устройство

- `js/ref.js` — справочные таблицы (пределы по классам, таблица А.1, время отбора).
- `js/calc.js` — расчёты.
- `js/store.js` — хранение, экспорт, импорт.
- `js/protocol-skch.js`, `js/protocol-tivl.js` — печатные формы протоколов.
- `js/app.js` — экраны ввода.

Перед применением в аккредитованной деятельности сверьте справочные значения и результаты
расчётов с действующими редакциями стандартов и проведите валидацию по своей процедуре.
