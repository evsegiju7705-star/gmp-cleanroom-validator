# Квалификация чистых помещений — расчётный модуль (MVP)

Локальное одностраничное приложение для расчётов при квалификации чистых помещений
(Приказ Минпромторга № 916, Приложение № 1 / EU GMP Annex 1 / ГОСТ Р ИСО 14644-1).

## Запуск
- Локально: открыть `index.html` двойным щелчком (работает по протоколу `file://`).
- GitHub Pages: опубликовать содержимое папки как есть, сборка не нужна.

Данные хранятся только в `localStorage` браузера и в файлах JSON (экспорт/импорт).
Сетевых запросов приложение не делает.

## Структура
```
cleanroom-qual/
├── index.html          разметка приложения
├── css/
│   ├── base.css        переменные, типографика, элементы форм
│   ├── app.css         компоновка экрана, таблицы, статусы
│   ├── protocol.css    протокол: просмотр и печать                 (шаг 4)
│   └── print.css       печать экрана ввода (без протокола)
└── js/
    ├── gmp-limits.js   справочник норм GMP / ИСО 14644-1          (шаг 2)
    ├── state.js        модель данных, localStorage, JSON           (шаг 2)
    ├── calc.js         расчёты и оценка соответствия               (шаги 2–3)
    ├── measurements.js динамические таблицы карты замеров          (шаг 3)
    ├── protocol.js     печатная форма протокола                    (шаг 4)
    └── app.js          инициализация, привязка форм, справочник    (шаг 2)
```

Скрипты подключены как обычные (не ES-модули): модули не загружаются по `file://`.
Все файлы используют общее пространство имён `window.CRQ`.

## Этапы
1. Файловая структура — готово.
2. Базовая разметка и справочник норм GMP — готово.
3. Логика расчётов карты замеров — готово.
4. Печатная форма протокола — готово.

## Важно
Справочные значения внесены по редакциям документов, указанным в `js/gmp-limits.js`.
Перед использованием в GMP-среде сверьте их с действующими редакциями и
валидируйте приложение как компьютеризированную систему (расчётный инструмент).
